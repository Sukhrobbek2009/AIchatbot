The 4-part formula

You don't need magic words. Cover these four things and your answers improve immediately.

🎭
1 · ROLE

Who should it be?

“You are a senior Python developer / a friendly nutritionist / a strict editor.”

🎯
2 · TASK

What exactly to do?

One clear verb: write, fix, compare, translate, summarize, explain.

🧩
3 · CONTEXT

What should it know?

Audience, goal, constraints, your level, paste the data or code.

📐
4 · FORMAT

How should it look?

Bullets, table-like list, 100 words, JSON, a .docx file, step by step.

Vague“Write about marketing.”

No audience, no goal, no length. You get a generic essay.

Specific“Write 5 Instagram post ideas for a small bakery in Tashkent targeting students. Friendly tone, each with a hook and a call to action.”

Generating files & reading documents

Switch to 📄 Files mode and describe the file. The bot writes it and sends it as a download.

📎

What it can create

Code files (.py .js .html .css .sql .sh), data (.csv .json .yaml), text (.md .txt) and Word documents (.docx). You can ask for several files at once.

📥

What it can read

Send a photo, a PDF, or a text/code file and write your question in the caption. Up to 10 MB.

Create a one-page CV in Word for [name], a [role] with [N] years of experience. Sections: Summary, Experience, Skills, Education. Use bullet points and a professional tone.
Generate three files: index.html, style.css and script.js for a [to-do list] web app. Modern design, dark mode, saves to localStorage.
Make a CSV with 20 realistic rows of fake customer data: id, name, email, country, signup_date (2024-2025), plan (free/pro).

💡 Under any answer tap 📎 Save as file to download it. Tap ✂️ Shorter, 📖 Detailed or 🔄 Redo to refine — no need to retype.

Level-up techniques

🪜

Ask for steps

“Think through this step by step, then give the final answer.” Great for math, logic and debugging.

🧪

Show an example

Paste one sample of the output you want. “Format every answer like this: …” beats a long description.

🚧

Set constraints

“Max 80 words”, “no jargon”, “only use the data below”, “don't change the function signature”.

🔁

Iterate

Treat it as a conversation. “Make it funnier”, “shorter”, “now for beginners”. The bot remembers recent messages.

🧹

Start fresh

Switching topics? Tap 🧹 New chat so old context doesn't leak into the new answer.

🔍

Ask it to check itself

“List your assumptions”, “What could be wrong with this answer?”, “Cite which part of my text you used.”

Before answering, ask me up to 3 clarifying questions if anything is ambiguous. Then give the answer in under 150 words.

Common mistakes

Too vague“Help me with code” → say the language, the goal, and paste the code and the error.
Many tasks in oneSplit big requests: outline first, then each part. Quality goes up.
No success criteriaSay what “good” means: length, audience, tone, must-include points.
Hidden contextThe bot only knows what you tell it. Paste the relevant text instead of “the thing from before”.
Trusting blindlyFor facts, numbers, medical, legal or financial topics, verify with a trusted source. Test generated code before using it.
Sharing secretsNever paste passwords, API keys, or private personal data into any chat.

FAQ

Which language should I write in?

Any. Use /lang to set the interface language. The bot answers in your language by default; to force another, say “answer in German”.

The answer stopped mid-way.

Very long answers hit a length limit. Write “continue” and it picks up where it stopped.

How do I stop an answer?

Tap ⏹ Stop under the animated message. Whatever was written so far is kept.

Can it browse the internet or remember me forever?

No live browsing. It remembers only your recent messages in the current chat; /new clears them.

Can it generate images?

It can read images and write image prompts or SVG/HTML graphics, but it does not draw pictures itself.
